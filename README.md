# Bouhezila Company Landing Page

A beautiful, modern landing page showcasing the three main activities of Bouhezila Company.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Smooth Animations**: Elegant hover effects and scroll animations
- **Modern UI**: Clean, professional design with gradient backgrounds
- **Three Activity Sections**:
  - Bouhezila Industry
  - Bouhezila i-Tech
  - ELITA (Home & Design)

## Customization

### Update URLs

Open `index.html` and modify the `href` attributes in each activity card:

```html
<!-- Bouhezila Industry -->
<a href="https://industry.bouhezila.com" class="btn-link">

<!-- B i-Tech -->
<a href="https://itech.bouhezila.com" class="btn-link">

<!-- ELITA -->
<a href="https://elita.bouhezila.com" class="btn-link">
```

Replace these URLs with your actual company URLs.

### Customize Colors

Open `styles.css` and modify the CSS variables in the `:root` section:

```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    /* ... other variables */
}
```

### Update Contact Information

In `index.html`, update the footer contact links:

```html
<a href="mailto:contact@bouhezila.com">Contact</a>
<a href="tel:+1234567890">Phone</a>
```
